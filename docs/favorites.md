The **Favorites** tab highlights messages from people you care about so they never get lost in a busy room.

## Adding favorites

Type a username and click **Add**, or use the in-chat menu: click a user's name/avatar and choose **FAVORITE**. Remove anyone from the list with the **Remove** button.

---

## The Favorites & Friends list

The list shows everyone you've marked, with a **member / guest / mod** badge and a colored left edge:

- 🟡 **Fav Only** · 🔵 **Friend Only** · 🟢 **Friend & Fav**

Click any of those labels at the top to **filter** the list to that group; click **All** to show everyone. Each row's dropdown switches a user between Fav / Friend / both. **Click a username** to open their profile in a new tab.

---

## Highlight style & color

Same four styles as [Alerts](alerts.md):

| Style | Look |
|---|---|
| **Subtle** | Faint left border + gradient |
| **Strong highlight** | Solid background tint |
| **Bold** | Bold text |
| **Box** | Full border around the message |

**Highlight color** options:

- **Default (gold)**
- **Use the sender's username color** — matches each favorite's own name color
- **Custom color** — pick any color; it's contrast-checked against the chat background so it stays readable

Changing the style or color re-applies instantly to messages already on screen.
