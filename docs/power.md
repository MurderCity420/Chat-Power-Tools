# Power

[← Back to README](../README.md) · [All docs](getting-started.md)

The **Power** tab bypasses site-enforced rate limits and muting. These are client-side changes — the server may still independently enforce its own rules.

## Power features

- **Disable spam check** — removes the client-side duplicate/flood detection so you can send repeated or similar messages without the local script blocking them.
- **Remove chat delay** — drops the client-side cooldown between chat messages, allowing you to send messages back-to-back.
- **Remove action delay** — removes the delay between other actions (tips, ratings, cam interactions, etc.).
- **Auto-clear mute flags** — automatically clears any mute state the site applies to your session, keeping you able to chat.

> **Use responsibly.** These features affect only the client-side checks in your browser. The server has its own rate-limiting and may still reject, throttle, or mute regardless of these settings.
